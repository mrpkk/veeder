# veeder — ежедневный отчёт «Индекс реальности платежей»

Telegram-бот, который раз в сутки отдаёт отчёт по платежам в крипте.
Монетизация встроена: подписка оплачивается **Telegram Stars** — без KYC,
без блокчейна и без задержки сети.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | тизер с бесплатной частью отчёта |
| `/report` | полный отчёт, только для подписчиков |
| `/subscribe` | оплата подписки Stars |
| `/my` | текущий статус подписки |
| `/help` | справка |

## Запуск

```
python3 bot.py        # поллинг
```

aiogram 3.x, оплата через XTR.

## Состояние

Код есть, монетизация предусмотрена. Запущен ли бот — проверять в
списке user-юнитов; в этой папке подтверждения работающего процесса нет.

## Почему важно

Это единственный продукт в портфеле, где путь до первой выручки
**не требует блокчейна**: Stars списываются внутри Telegram, получатель
не платит комиссию сети и не ждёт подтверждения.

В отличие от `rta` и `drift`, которым нужен реальный USDC на mainnet,
здесь платит подписчик внутри мессенджера.
