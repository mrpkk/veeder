# VEEDER · Индекс реальности платежей в крипте

**Что это.** Телеграм-бот, который каждый день считает по публичным данным
блокчейна, сколько платежей, сколько за ними денег, и каков разрыв между
числом операций и реальной ценностью. Продаёт полный отчёт по подписке
за Telegram Stars.

**Зачем он.** x402 провёл 154 млн транзакций агентов — а расчёт за неделю
$41 800 (≈ $0.00027 на транзакцию, −93% г/г). Либо агенты покупают воздух,
либо метрика надута. VEEDER это измеряет, а не пересказывает.

## Что уже работает (проверено)

| Компонент | Статус |
|---|---|
| `indexer.py` — сбор 1000 переводов USDC через Etherscan, расчёт индекса | ✅ на живых данных |
| `bot.py` — aiogram 3.30, подписка Stars (XTR), команды | ✅ хендлеры собраны |
| Прокси Tor SOCKS5 для api.telegram.org | ✅ getMe 2.6 с |
| Монетизация: `send_invoice`, XTR, `pre_checkout`, `successful_payment` | ✅ сигнатура верна |

**Индекс реальности** (0–100) считает долю «шума»: мелкие переводы,
повторяющиеся суммы, «круглые» суммы, концентрация отправителей.
Ниже 35 → «экономики нет», 35–60 → «зарождается», выше 60 → «есть».

---

## ⚠️ Честно о данных

Индекс меряет **профиль переводов USDC/USDT в сети Ethereum** (DeFi, биржи,
расчёты). Это НЕ платежи агентов — это другая популяция. Кейс x402 приведён
отдельным блоком как задокументированный крайний случай. Признаки
«агентности» в индексе эвристические. Причинно-следственных выводов бот
не делает.

## Запуск

```bash
cd /media/Sruti/iamthat/work/crypto/veeder

# 1. Создать бота у @BotFather → получить токен
# 2. Прописать в ~/.env (см. env.veeder.example):
#    VEEDER_BOT_TOKEN=...  VEEDER_STARS=25  VEEDER_PROXY=socks5h://127.0.0.1:9050

# 3. Проверить индекс в одиночку
python3 indexer.py --force

# 4. Запустить бота
python3 bot.py
```

## Команды бота

- `/start` — тизер (бесплатно)
- `/report` — полный отчёт (нужна подписка)
- `/subscribe` — оформить подписку (Stars)
- `/my` — статус подписки
- `/help` — справка

## Как заработать

Подписка: `{VEEDER_STARS}` Stars = 30 дней. Оплата мгновенная, без KYC и
карт — это самый быстрый крипто-рельс, доступный из этой сети.
